# AI Community Playbook

面向 AI 学习社群和技术社区的实操方法与模板。

## What this repository covers

- Community positioning
- Member onboarding
- Content cadence
- Online activity design
- User feedback loops
- Case review
- Privacy and moderation

## Principles

1. 先明确成员为什么留下，再设计活跃动作。
2. 内容、活动和反馈必须服务于成员的具体进步。
3. 区分规模、活跃、产出和转化，不用单一数据证明效果。
4. 公开案例前做匿名化并取得必要授权。
5. 记录失败实验，不把方法论包装成保证结果。
